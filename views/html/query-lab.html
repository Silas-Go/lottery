READ MODEL COMPOSITION

MaterialDetailDTO 如何组成

这里只呈现一张整体映射。Direct 每次现场组装，Redis Cache-Aside 命中后直接返回同一份最终 DTO。

基础信息 materials 名称、价格、库存、稀有度与来源
组成材料 material_components + materials 关系表 JOIN 材料表，形成 components[]
交易统计 trades COUNT / AVG / MAX
评价统计 reviews AVG / COUNT
最终结果 MaterialDetailDTO 接口返回对象 · Redis 缓存一份完整 JSON
公共 DTO 不包含用户购买状态，避免热点缓存按用户维度膨胀。
