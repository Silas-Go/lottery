ARCHITECTURE EXPERIMENTS

选择一个技术问题

悬停预览，点击名称可锁定展开。点击方片展开。 三项实验互不构成前置条件。

你会观察到什么

同一份星髓档案分别经过 MySQL Direct 与 Redis Cache-Aside，在真实查询潮汐下呈现不同的延迟、SQL 次数与连接池压力。

你能学到什么
  • Cache-Aside 命中与回源
  • 热点数据与缓存击穿
  • 缓存对数据库压力的影响
进入查询实验→
你会观察到什么

星髓库存提交到 MySQL 后，对比同步删除 Redis 与 Outbox + MQ 异步失效，观察响应路径、旧读窗口和最终库存。

你能学到什么
  • 数据库与缓存的权威边界
  • 本地事务与可靠事件
  • 最终一致性的时间窗口
进入购买实验→
你会观察到什么

让唯一用户并发争抢星髓活动库存，并把限流保护单独测量，观察 Lua 准入、MQ 削峰和订单状态推进。

你能学到什么
  • 令牌桶入口限流
  • Redis Lua 原子库存准入
  • 异步落单与幂等状态机
进入秒杀实验→
